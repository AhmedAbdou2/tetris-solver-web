PARSER

DFS in AreConnected()

DFS traverses the occupied cells of a Tetromino through their horizontal and vertical neighbors.

AreConnected(cells) → bool

Goal: Verify that all four occupied cells are connected.

SOLVER

DFS in Solve()

The solver explores possible piece placements recursively. When a search path fails, it undoes the previous placement and tries another possibility.

Solve(i, grid, tetrominoes) → bool

Goal: Find a complete valid arrangement using DFS and Backtracking.

Important distinction: DFS is a graph traversal/search strategy. Backtracking is a search technique that undoes a decision when the current path cannot lead to a solution. They work together in the recursive Tetris solver, but they are not the same concept.

Function Documentation

Responsibilities and relationships of each function.

01

cmd / main.go

Application entry point and execution flow

01 ENTRY POINT

main()

func main()

Starts the application and coordinates the complete execution pipeline.

Responsibilities
  • Read the input file path.
  • Invoke the parser.
  • Pass Tetrominoes to the solver.
  • Print the final grid.
02 INPUT

ReadFile(path)

File Reading Stage

Reads the input content from the provided file path so it can be processed by the parser.

Responsibilities
  • Access the input file.
  • Read its content.
  • Provide the content to the parsing stage.
02

parser / parser.go

Input parsing and Tetromino validation

03 PARSER

Parse(content)

[]Tetromino

Converts the input text into a collection of Tetromino structures.

Responsibilities
  • Split the input into 4 × 4 blocks.
  • Extract occupied cell coordinates.
  • Validate dimensions and characters.
  • Check that every piece has four filled cells.
  • Validate connectivity using AreConnected.
04 DFS VALIDATION

AreConnected(cells)

bool

Checks whether the four occupied cells form one connected shape.

Responsibilities
  • Start DFS from one occupied cell.
  • Explore horizontal and vertical neighbors.
  • Track visited cells.
  • Return true when all four cells are visited.
03

solver / solver.go

Grid management, recursive search and backtracking

05 TRANSFORMATION

Normalize(cells)

[]Cell

Moves the occupied cells to the top-left of their coordinate space.

Responsibilities
  • Find the minimum row and column.
  • Subtract them from all coordinates.
  • Preserve the original piece orientation.
06 GRID

MakeGrid(size)

[][]byte

Creates an empty square grid with the requested dimensions.

Responsibilities
  • Create size × size rows and columns.
  • Initialize every cell with a dot (.).
  • Return the empty grid.
07 VALIDATION

CanPlace(grid, t, r, c)

bool

Determines whether a Tetromino can be placed at the requested position.

Responsibilities
  • Check grid boundaries.
  • Check for occupied cells.
  • Prevent overlapping pieces.
  • Return whether the placement is valid.
08 GRID OPERATION

PlacePiece(grid, t, r, c, label)

Grid Mutation

Writes the Tetromino label into the corresponding grid cells.

Responsibilities
  • Use the Tetromino cell coordinates.
  • Apply the row and column offsets.
  • Write the piece label into each occupied cell.
09 BACKTRACKING

RemovePiece(grid, t, r, c)

Grid Mutation

Removes a previously placed Tetromino when a search path fails.

Responsibilities
  • Visit the piece's occupied cells.
  • Restore those positions to empty cells.
  • Allow the solver to try another placement.
10 MAIN SOLVER

FindSmallestSquare(tetrominoes)

[][]byte

Finds the smallest square grid that can accommodate all Tetrominoes.

Responsibilities
  • Calculate an initial grid size.
  • Normalize the Tetrominoes.
  • Create a square grid using MakeGrid.
  • Invoke Solve to search for an arrangement.
  • Increase the grid size when no solution fits.
  • Return the first successful grid.
11 DFS / RECURSION

Solve(i, grid, tetrominoes)

bool

Recursively searches for a valid arrangement of all Tetrominoes.

Responsibilities
  • Check whether all pieces have been placed.
  • Iterate over candidate positions.
  • Validate positions using CanPlace.
  • Place valid pieces using PlacePiece.
  • Recursively attempt the next piece.
  • Undo unsuccessful placements using RemovePiece.
12 OUTPUT

PrintGrid(grid)

Grid Output

Prints the final solved grid row by row.

Responsibilities
  • Iterate through grid rows.
  • Print the cell labels.
  • Print empty cells as dots.
